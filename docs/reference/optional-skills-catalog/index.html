Optional Skills Catalog

Optional skills ship with haishui-agent under optional-skills/ but are not active by default. Install them explicitly:

haishui skills install official/<category>/<skill>

For example:

haishui skills install official/blockchain/solana
haishui skills install official/mlops/flash-attention

Each skill below links to a dedicated page with its full definition, setup, and usage.

To uninstall:

haishui skills uninstall <skill-name>

Contributing Optional Skills​

To add a new optional skill to the repository:

  1. Create a directory under optional-skills/<category>/<skill-name>/
  2. Add a SKILL.md with standard frontmatter (name, description, version, author)
  3. Include any supporting files in references/, templates/, or scripts/ subdirectories
  4. Submit a pull request — the skill will appear in this catalog and get its own docs page once merged
